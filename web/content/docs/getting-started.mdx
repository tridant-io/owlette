## step 1: create an account

1. Go to [owlette.app](https://owlette.app)
2. Click **Register** and create an account with email/password or Google sign-in
3. Set up **two-factor authentication**. It's required, and either option satisfies it on its own:
   - a **passkey** (Windows Hello, Touch ID, Face ID, a security key, or a password manager like 1Password) signs you in and clears 2FA in one step, with no code to type
   - an **authenticator app** gives you 6-digit codes — these run on desktop as well as mobile, so you don't need a phone
4. Save the **backup codes** you're shown at the end — they're how you get back in if you lose the device

---

## step 2: create a site

Sites organize your machines — think of them as locations, departments, or projects.

1. Click **"new site"** in the dashboard (or **"Create Your First Site"** from the empty state)
2. Enter a **site name** (e.g., "NYC Gallery", "Main Office")
3. The **site ID** is auto-generated from the name — expand **"customize site ID"** only if you want to set a specific ID
4. The **site timezone** is detected from your browser — expand **"change timezone"** if the site lives somewhere else. Process schedules at this site run on this clock; see [timezones](/docs/dashboard/timezones)
5. Click **"create site"**

## step 3: install the agent

### download

The dashboard header has two installer buttons side by side — pick the one that matches where you are:

- **download** — if you're already working **on the machine you want to monitor**, click this to download the latest installer directly.
- **copy link** — if you're **remoting into** the machine, click this to copy the installer link, then paste it into a browser on that machine to download it there — no file transfer needed.

![the download and copy-link buttons in the dashboard header](/docs-screens/getting-started-install-buttons.png)

### install & connect

1. Run the installer **as Administrator** on your target machine
2. Follow the setup wizard
3. The owlette window opens on **join a site**, showing a **pairing phrase** (3 random words), the authorization link, and which owlette server it belongs to
4. Click **open owlette.app/add** in that window to authorize from this machine, then select a site and click **"Authorize"**
5. Or authorize from a phone or another computer by opening the displayed URL and entering the pairing phrase
6. The agent receives credentials and connects — done

<Callout type="idea" title={"Bulk deployment"}>

For deploying to many machines, use the `/ADD=` flag with a pre-authorized phrase from the dashboard. See [Installation → Silent Install](/docs/agent/installation#method-2-silent-install-with-add).

</Callout>

## step 4: verify

Within 30 seconds of installation, your machine should appear in the dashboard:

![online machine card](/docs-screens/machine-card.png)

| check | what to look for |
|-------|-----------------|
| **Machine visible** | Machine card appears in your site with a green "Online" indicator |
| **Metrics flowing** | CPU, memory, disk percentages updating |
| **System tray** | Owl icon visible in the Windows notification area |

---

## step 5: add processes to monitor

Now that your machine is connected, tell owlette which applications to watch:

1. Click on your machine in the dashboard
2. Click **"add process"**
3. Give it a **name** (e.g., "TouchDesigner")
4. Set **launch mode** to **always on** — owlette starts the process and relaunches it if it crashes. Choose **scheduled** instead to run it only inside time windows you define; the gear at the end of the control opens the schedule editor in any mode.
5. Enter the **executable path** (e.g., `C:\Program Files\Derivative\TouchDesigner\bin\TouchDesigner.exe`)
6. Click **"create process"**

![add process dialog](/docs-screens/add-process-dialog.png)

The agent immediately begins monitoring the process. If it crashes, owlette restarts it within 10 seconds.
