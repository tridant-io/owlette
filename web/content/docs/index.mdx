owlette is a cloud-connected process manager and remote deployment system for
the machines behind installations: TouchDesigner shows, digital signage, kiosks
and media servers. a small agent runs as a system service on each machine,
keeps your applications running, and reports to a web dashboard. from the
dashboard you monitor the fleet, change what runs where, push project files,
take over a screen, and ask an AI assistant to investigate.

the agent runs on three platforms:

- **Windows** 10 or later, 64-bit, as a Windows service
- **macOS** 15 or later on Apple silicon, as a launchd daemon
- **Linux**, Ubuntu 24.04, as a systemd unit

each machine also gets the owlette desktop app: the local window, plus a tray
icon on Windows and Linux or a menu bar item on macOS, for the same
configuration the dashboard edits. not every feature reaches every platform;
[platform support](/docs/reference/platform-support) lists what works where.

new to owlette? [getting started](/docs/getting-started) takes you from an
account to your first monitored machine in a few minutes.
