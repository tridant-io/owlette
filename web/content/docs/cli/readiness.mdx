title: "CLI readiness matrix"

legend:

- **ready** — the command calls public API routes that are live.
- **ready preview** — the command works, but the route behind it is still a preview (see the row).
- **local** — the command changes only local CLI state.
- **stub** — the command is registered and exits `3` with the stub envelope.
- **not registered** — no CLI verb exists; the row shows where the operation lives instead.

## top-level commands

| command | status | reference page | routes |
|---|---|---|---|
| `owlette auth login` | ready | [auth](/docs/cli/reference/auth) | `POST /api/cli/device-code`, then `POST /api/cli/device-code/poll` |
| `owlette auth status` | ready | [auth](/docs/cli/reference/auth) | alias of `owlette whoami`; `GET /api/whoami` |
| `owlette auth logout` | local | [auth](/docs/cli/reference/auth) | none — clears the active profile's keychain or `credentials.json` entry and any legacy `config.toml` token |
| `owlette whoami` | ready | [whoami](/docs/cli/reference/whoami) | `GET /api/whoami` |
| `owlette version` | ready | [version](/docs/cli/reference/version) | `GET /api/version` (no auth) |
| `owlette rollback <roostId>` | ready | [rollback](/docs/cli/reference/rollback) | `GET /api/roosts/{roostId}`, `GET /api/roosts/{roostId}/versions/{versionRef}/diff`, `POST /api/roosts/{roostId}/rollback` |
| `owlette listen` | ready preview | [listen](/docs/cli/reference/listen) | `GET /api/events/stream?siteId=<siteId>`; the stream carries liveness events only until production event fanout ships |
| `owlette trigger <event>` | ready | [trigger](/docs/cli/reference/trigger) | direct mode posts to your URL and calls no route; `--via-api` calls `POST /api/webhooks/probe?siteId=<siteId>` |

## webhook noun

`owlette webhook` is not a command: `owlette webhook …` fails with `unknown command` and exits `1`. the subscription routes are live and are used by the dashboard and the SDKs. the CLI covers this area only through `owlette listen` and `owlette trigger`.

| operation | status | reference page | routes |
|---|---|---|---|
| create a subscription | not registered | [webhook](/docs/cli/reference/webhook) | `POST /api/webhooks?siteId=<siteId>` |
| list subscriptions | not registered | [webhook](/docs/cli/reference/webhook) | `GET /api/webhooks?siteId=<siteId>` |
| get a subscription | not registered | [webhook](/docs/cli/reference/webhook) | `GET /api/webhooks/{webhookId}?siteId=<siteId>` |
| update a subscription | not registered | [webhook](/docs/cli/reference/webhook) | `PATCH /api/webhooks/{webhookId}?siteId=<siteId>` |
| delete a subscription | not registered | [webhook](/docs/cli/reference/webhook) | `DELETE /api/webhooks/{webhookId}?siteId=<siteId>` |
| rotate the signing secret | not registered | [webhook](/docs/cli/reference/webhook) | `POST /api/webhooks/{webhookId}/rotate-secret?siteId=<siteId>` |
| list deliveries | not registered | [webhook](/docs/cli/reference/webhook) | `GET /api/webhooks/{webhookId}/deliveries?siteId=<siteId>` |
| get a delivery | not registered | [webhook](/docs/cli/reference/webhook) | `GET /api/webhooks/{webhookId}/deliveries/{deliveryId}?siteId=<siteId>` |

## invariants

- no registered CLI command calls `/api/admin/*`.
- `owlette chat` calls the canonical `/api/hoot/conversations` routes. `/api/cortex/conversations` and `/api/chat` are compatibility aliases for the same handlers.
- `machine live-view` is the only stub.
- `installer upload`, `roost diff` and `roost deploy` have a `--version` option that the global `--version` flag intercepts unless it is written `--version=<value>`.
