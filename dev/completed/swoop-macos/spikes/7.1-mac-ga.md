The first two commands failed at the agent with `No installer URL provided for update`: the API accepts a bare
`update_owlette`, but the agent needs `installer_url`, `target_version` and `checksum_sha256`, which the
dashboard fills from `/api/installer/latest` per platform. Sent again with them (scratchpad `send_update.py`):

- **TEC-MBA** (macOS, 4.0.6 → 4.1.0): `installer: Package name is owlette 4.1.0 … The upgrade was successful.`
  at 22:31; `app.owlette.agent` and the app relaunched; the API shows `agentVersion 4.1.0`, online,
  `capabilities.swoop: 1`. A swoop session was requested at 22:32:02, so the owner's next session ran on the
  released build.
- **TEC-A4D** (Windows, this box, 4.0.6 → 4.1.0): `OWLETTE SELF-UPDATE INITIATED` 22:31:28, download 46,390,734
  bytes, service back at 22:32:33 with `Version : 4.1.0`, the desktop exe 4.1.0, the API `agentVersion 4.1.0`,
  online, `capabilities.swoop: 1`. (The plan's "one Windows machine" became this box because `hostname` is
  TEC-A4D; TEC-B4A stays on 4.0.6.)
