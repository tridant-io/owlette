## The build job

**The release flow's job.** `~/Library/LaunchAgents/app.owlette.build-dev.plist` runs, in `~/src/owlette`:

1. `git fetch`, then `git checkout dev`, then `git reset --hard origin/dev`.
2. `agent/build/macos/build.sh --installer-identity <Developer ID Installer> --notarize <notary profile>`,
   with `APPLE_SIGNING_IDENTITY` set to the Developer ID Application.

Its log is `~/src/signed-build-dev.log`, which ends `BUILD-EXIT=`. The job names `dev`, so it cannot build this
branch. It was left untouched.

**This branch's job, written beside it.** `~/Library/LaunchAgents/app.owlette.build-swoop-mac.plist` runs the
same command in `~/src/owlette-swoop-mac` on `swoop/macos`, with `reset --hard origin/swoop/macos`. Its log is
`~/src/signed-build-swoop-mac.log`, and the last line is `BUILD-EXIT=<code>`.

It differs from the release job on purpose in one way: `RunAtLoad` is false, so it never builds at login.

- It was registered on 2026-09-28 with `launchctl bootstrap gui/$(id -u) <plist>`. `launchctl print` showed
  `runs = 0`.
- It runs only when kicked: `launchctl kickstart -k gui/$(id -u)/app.owlette.build-swoop-mac`.
- After a logout, launchd registers it again at login and still does not run it.

**The first run, after Task 1.1 landed (2026-09-28, about 19:55 to 20:00 Mac time), ended `BUILD-EXIT=69`.**

- The log opens `HEAD=45718a8e VERSION=4.0.6`.

  app, and built the product: `agent/build/macos/Owlette-Installer-v4.0.6.pkg` in the branch worktree, 137 MB.

  --team-id <team id>`.
